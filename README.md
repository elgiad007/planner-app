# My Pastel Planner
A web app to emulate a DayTimer planner.

An offline-capable React/TypeScript iPad planner with monthly/weekly pages, vector ink, IndexedDB saving and JSON backup/restore. Phase 2 adds animated page curls, finger swipes and edge taps.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Build with `pnpm build`, test with `pnpm test`, and serve the production build with `pnpm preview`. Upload only the contents of `dist/` to the domain root.

See [documentation](doc/README.md), [hosting instructions](doc/running-and-hosting.md), and the [phase 2 iPad acceptance checklist](doc/phase-2-testing.md). Custom inserts and PDF export are later phases. No deployment has been performed.
