# My Pastel Planner
A web app to emulate a DayTimer planner.

An offline-capable React/TypeScript iPad planner with monthly/weekly pages, vector ink, IndexedDB saving and JSON backup/restore. Phase 3 adds custom two-page inserts, page organization, bookmarks, highlighter, pencil-style ink and stroke selection/movement alongside animated page curls.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Build with `pnpm build`, test with `pnpm test`, and serve the production build with `pnpm preview`. Upload only the contents of `dist/` to the domain root.

See [documentation](doc/README.md), [hosting instructions](doc/running-and-hosting.md), and the [phase 2 iPad acceptance checklist](doc/phase-2-testing.md). See the [Phase 3 acceptance checklist](doc/phase-3-testing.md). PDF export remains Phase 4. No deployment has been performed.
