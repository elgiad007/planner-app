# Keyboard shortcuts

Connect a keyboard to use these shortcuts. They are also listed in the app’s Help screen; writing-tool buttons show their shortcuts in tooltips.

| Keys | Action |
| --- | --- |
| ← / → | Previous / next spread in binder order |
| T | Go to today (confirm when opening a year outside 2027) |
| Home | Open the planner’s home view |
| M / W | Switch to month / week view for the current date |
| G | Open navigation and focus Jump to date |
| P / N / H | Pen / pencil / highlighter |
| E / V / B | Eraser / select and move handwriting / browse dates |
| Hold Space | Temporarily pan; release to return to your current tool |
| [ / ] | Decrease / increase writing-tool width within its normal limits |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z / Ctrl+Y | Redo |
| + / − | Zoom in / out in 25% steps, from 100% to 250% (`=` also zooms in) |
| 0 | Reset zoom to 100% |
| Esc | Close an open menu or Help; otherwise clear handwriting selection |
| ? | Open Help and the shortcut list |
| Tab / Shift+Tab | Move to the next / previous control |
| Enter / Space | Activate a focused button |
| ↑ / ↓ | Move through controls in an open dock menu |

On a Mac, use Command instead of Ctrl for undo and redo. Ctrl/Command zoom shortcuts continue to control browser zoom.

Planner shortcuts pause in text, date, range, select, and other input fields so their normal editing keys work. Shortcuts respect active writing, page-turn, and operation locks. Holding a key does not repeatedly turn pages or undo edits. Space on a focused button activates that button; to pan, first focus the planner spread or click the paper. Releasing Space, switching windows, or hiding the app ends temporary panning.

Help keeps keyboard focus inside its dialog. Escape or Back to my planner closes it and returns focus to the previous control.
