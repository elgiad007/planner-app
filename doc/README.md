# User guide

My Pastel Planner keeps your calendar, handwriting, text, and stamps on your device. Start with the [app overview](../README.md) for its features.

- [Data storage and backups](data-storage.md): save editable planner files, restore a backup, transfer to another device, and recover from save problems.
- [Keyboard shortcuts](keyboard-shortcuts.md): navigation, writing tools, zoom, and undo/redo.
- [Running, hosting, and updating](running-and-hosting.md): install the app, upload it to your own hosting service, and install updates.

## Using text blocks

Choose **Text** in the writing toolbar, then click or tap a page. Enter multiline text and set its font size and box dimensions, then choose **Save text**. Select a block using Text or Select / move. Drag the block to move it, or its bottom-right corner to resize it. **Edit text** reopens the contents and size controls; **Delete text** removes the selected block. **Done** clears selection.

The color palette sets new text color and recolors selected text. Text beyond the box is clipped; increase its height to show more lines. Undo/redo, backups, duplication, page turns, and PDF exports include text blocks.

## Using a phone

Mobile mode shows one page at a time and keeps its original proportions. It fills the available width in portrait and landscape; tall pages scroll instead of shrinking to fit the screen height. Use **Pan** to drag the page without writing, or scroll directly with a finger in **Browse dates**. **Fit page** shows the whole page; **Fill width** returns to the larger view.

Use **Tools** and **Options** to open or collapse the toolbars. The bottom arrows move through the left page, right page, and then the next spread. The page indicator shows **1/2** or **2/2**. Under **Options → Navigate → Layout**, choose **Auto**, **Book**, or **Mobile**. Auto uses mobile mode on narrow screens and phone-sized landscape screens. The layout choice stays on this browser; planner files and PDF page proportions stay the same.
